# Product brief

## Product statement

PrepCanvas is a local-first learning companion that turns fragmented study materials into a focused route to exam readiness.

## Problem

Students often have a workbook, notes, practice questions, model answers, and session transcripts, but no reliable way to combine them into an actionable preparation plan. Generic summarizers create more content without answering what to learn next or whether the learner can retrieve knowledge under exam conditions.

## Target user

An independent learner preparing for a knowledge-based exam from a finite set of source materials.

## Core job to be done

When an exam is approaching, help me identify my gaps, understand difficult topics, practise the right material, and decide whether I am ready.

## MVP journey

1. Create or select a subject.
2. Add materials on the Content page and build the study content with your own AI assistant; review it.
3. Complete a short diagnostic.
4. Receive a starting coaching strategy.
5. Learn one topic through explanation, example, recall, and feedback.
6. Practise one topic or the whole subject.
7. Run a mock exam with delayed feedback.
8. Review readiness and the next best action.

The bundled synthetic sample skips step 2. For your own subjects, step 2 happens once, outside the app, with the coding agent or chat assistant you already use; PrepCanvas validates the result and runs everything after that locally.

## Success criteria

- A new user can run the app, and build their own subject, without an API key.
- The public demo contains no private or institutional material.
- Progress remains isolated by subject.
- Every demo explanation and question has a visible source label.
- The user can understand why the readiness score changed.
- The app recommends one concrete next action.

## Non-goals for the public MVP

- production authentication or multi-user hosting
- guaranteed exam-grade prediction
- autonomous ingestion of every document format
- voice agents
- required cloud AI services
